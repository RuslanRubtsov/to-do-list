# to-do-list

To-do web application built as a technical-interview showcase: Angular frontend, Spring Boot REST API, MySQL.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (RuslanRubtsov/to-do-list) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
